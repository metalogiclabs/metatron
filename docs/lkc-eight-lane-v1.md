# Lean Kernel Eight-Lane Programme V1

This layer is deliberately outside Metatron's trusted nucleus.

The qualified minimal warrant graph remains unchanged. This programme appends
only content-addressed evidence nodes for the eight Stage 1 problems and derives
search priority as disposable policy.

Current high-priority lanes:

1. Primecount — prove the 11.17%-faster bitset probe before staging it.
2. Partition — continue verified theorem-to-runtime compression from V12 before
   spending another external PMU run.
3. SHA256 — prove or refute the deferred-mask algebra probe.
4. Permanent — obtain a cheap row-order proof or abandon reverse-row for a
   stronger representation family.
5. Rule110 — ignore the score-irrelevant generic V64 fallback and optimize only
   the scored 2/4/8-step paths.
6. Mertens — abandon the regressing bitset family; test summatory/quotient-block
   recurrences.
7. Fibonacci — abandon the regressing shift transfer and search a different
   reduction-spine representation.
8. Polydisc — abandon the effectively flat fixed-shape V4 family and search a
   different fixed-degree algebraic representation.

The SAIR Contributor Network snapshot currently contains two public packages,
both for Fibonacci, and none for the other seven problems. Their existence is
recorded as evidence, not treated as a score or promotion signal.
