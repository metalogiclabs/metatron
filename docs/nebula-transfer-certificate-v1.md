# Nebula Transfer Certificate V1

Nebula transfer is an external evidence claim. It does not add trusted runtime
types to Metatron.

A transfer certificate states that a developmental lineage already earned in
one warranted world lowers deterministic acquisition cost on a genuinely
independent residual family.

The inherited lineage is frozen:

```text
K1 = sort
K2 = pi
K3 = pi_continuation
```

The four-arm control is:

```text
cold
warm12
warm123
sham123
```

A positive certificate requires:

- exact source commit, run, and artifact digest;
- an independently declared target family;
- byte-identical acquisition semantics;
- byte-identical held-out semantics;
- the same target witness across all arms;
- `warm123 < cold` on deterministic acquisition cost;
- at least one strict inherited causal marginal;
- real K3 strictly better than sham K3;
- no held-out reversal.

The validator is `scripts/check_nebula_transfer_certificate.py`.

A positive transfer certificate means:

> previously warranted developmental structure causally lowers acquisition
> cost on one independent residual family under a frozen substrate and fixed
> observation protocol.

It does not mean universal transfer, open-ended self-improvement, or that every
inherited developmental product is useful outside its source lineage.
