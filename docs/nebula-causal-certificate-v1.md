# Nebula Causal Certificate V1

Nebula is not a new trusted runtime type.

The Metatron nucleus remains only:

```text
Node(kind, payload, premises)
append(Log, Node) -> Log
```

A Nebula ignition claim is an external causal certificate whose accepted facts
may later be appended as ordinary warranted nodes.

The minimal certificate is:

```text
G1 -> (rho2, K2) -> G2 -> (rho3, K3) -> G3
```

with exact source/run/artifact hashes and these mandatory counterfactual stamps:

```text
W | KO | SHAM | RESTART | SEALED_SEMANTICS=IDENTICAL
```

Each recurrence arrow must certify both:

```text
next residual newly available
next developmental realizer newly available
```

and the realizer must satisfy the frozen developmental constitution.

This prevents a mere chronological sequence of three successful searches from
being upgraded into a causal recurrence claim.

`scripts/check_nebula_certificate.py` validates only certificate shape and
claim boundaries. It is external evidence policy, not trusted Metatron
semantics.

No V41 certificate is committed until the real Lean-kernel experiment produces
a green run with exact evidence hashes.
