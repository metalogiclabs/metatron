# Residual-Driven Interface V0

**Status:** executable falsification experiment  
**Branch:** `residual-driven-interface-v0`

## Question

Can Metatron derive its **next warranted reasoning interface from the current
consequential residual alone**, without a hand-authored residual-to-repair
rule?

This experiment deliberately keeps the claim finite.

## Frozen world

The carrier contains all 16 four-bit states.

The seed interface observes only bit 0. The frozen target future is full
four-bit identity.

The candidate language contains eight anonymous atomic capabilities. Lawful
closure contains three synergistic rules:

[
{a,b}\Rightarrow q_1,qquad
{c,d}\Rightarrow q_2,qquad
{e,f}\Rightarrow q_3.
]

No singleton generates any new observation. The final two atoms are inert
decoys.

These closure laws are the declared candidate semantics. They are **not**
residual-specific repair instructions.

## Selector contract

The selector receives only:

[
(U_t,;K_t,;\mathcal C)
]

where (U_t) is the current consequential residual, (K_t) the currently
installed atoms, and (\mathcal C) the declared candidate closure semantics.

It does **not** receive the target labels or a mapping from residual shapes to
repairs.

The frozen policy is generic:

1. find the smallest candidate-family cardinality producing positive residual
   reduction after lawful closure;
2. within that size maximize residual coverage;
3. use lexical order only as a deterministic tie-break.

Every choice is then independently re-enumerated and verified before a warrant
is appended.

## Warrant cycle

Each generation appends ordinary Nucleus nodes only:

[
\text{residual certificate}
\to
\text{candidate process}
\to
\text{verification}
\to
\text{capability warrant}.
]

The process payload is represented as a tiny port event structure whose two
synergistic events need not be serially ordered.

Reclosure derives the next interface from the live warranted capability nodes.

There are no new trusted runtime types.

## Controls

The gate requires:

- three generations from one generic developmental loop;
- no singleton may ignite the first generation;
- strict residual decrease at every promotion;
- final target sufficiency;
- exact restart reconstruction from canonical log serialization;
- diagnostic-only semantic sham leaves the interface unchanged;
- revoking G1 removes every causally downstream generation and restores the
  seed interface;
- complete candidate renaming preserves residual trace, process sizes,
  generation count, and final closure.

The rename control specifically attacks hidden syntactic repair rules.

## Expected finite trace

The four-bit world should yield

[
56\to24\to8\to0
]

future-demanded residual pairs, with three minimum positive process families of
size two.

The exact candidate names are not part of the claim.

## Claim boundary

A positive result establishes only:

> In this declared finite candidate semantics, a generic selector whose only
> problem-specific input is the current consequential residual can repeatedly
> discover, verify, warrant, and reclose the next interface without a
> hand-authored residual-to-repair mapping.

It does **not** establish unrestricted open-ended invention, globally optimal
multi-generation planning, or that the declared closure semantics can itself be
invented from nothing.
