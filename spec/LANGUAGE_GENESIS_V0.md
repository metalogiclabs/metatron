# Language Genesis V0

**Status:** executable falsification experiment  
**Branch:** `language-genesis-v0`

## Question

When the consequential residual is nonempty but **every process already
expressible in the current candidate language has zero gain**, can Metatron
certify that representational language as insufficient and warrant a new
generator schema from residual evidence alone?

## Frozen finite world

The carrier is all 16 four-bit states.

The seed interface exposes only coordinate 0. The future demand is full
four-bit identity.

The active process language consists of the permutation generators already
warranted and their complete compositional closure. Its observations are the
seed test pulled back through that closure.

Initially the active language contains no nontrivial generator.

## Declared meta-language

The meta-language is not a list of repairs. It is one generic schema family:

[
\operatorname{Swap}(i,j),
qquad
0\le i<j<4.
]

The six schema instances are generated mechanically from the interface arity.

Installing one schema adds the corresponding state transformation to the
active language. Reclosure computes the full permutation group generated by all
warranted schemas and derives every seed observation reachable through it.

This remains a declared finite meta-language. V0 does not claim to invent the
`Swap` constructor itself.

## Genesis criterion

Before every schema installation the experiment requires

[
U_t\ne\varnothing
]

and

[
\boxed{
\max_{p\in\operatorname{Cl}(\mathcal C_t)}
\operatorname{gain}(p,U_t)=0.
}
]

That is the executable language-insufficiency certificate: the current
language is fully reclosed and cannot make any further consequential progress.

Only then may the external meta-search consider schema extensions.

## Search contract

The schema selector receives only:

[
(U_t,;\mathcal C_t,;\text{declared schema family}).
]

It receives no target relation and no residual-to-schema table.

All schema instances have the same meta-cost. Selection maximizes generated
residual reduction after reclosure, retains the complete equal-gain frontier,
and uses the semantic swap pair—not the external schema name—as the
deterministic frozen tie-break.

Independent re-enumeration verifies the chosen schema before warrant.

## Expected developmental trace

The experiment should discover three language extensions:

[
\operatorname{Swap}(0,1),
\quad
\operatorname{Swap}(0,2),
\quad
\operatorname{Swap}(0,3),
]

not because those names are scheduled, but because each newly reachable
coordinate is the next minimum positive extension of the current residual.

The consequential residual should descend

[
\boxed{56\to24\to8\to0}.
]

Before each transition, the active language itself must have zero remaining
gain.

## Warrant lineage

Each generation appends only ordinary minimal-Nucleus nodes:

[
\text{language insufficiency}
\to
\text{schema candidate}
\to
\text{schema verification}
\to
\text{schema warrant}.
]

Later schema warrants depend causally on the earlier warranted developmental
state.

## Controls

Qualification requires:

- exact zero current-language gain before every Genesis;
- strict residual descent after every schema warrant;
- complete target closure;
- candidate-schema names can be replaced by unrelated names with identical
  semantic development;
- canonical restart reconstructs the final interface;
- diagnostic sham changes nothing;
- revoking G1 retracts all downstream schema warrants and restores the seed
  interface;
- trusted `nucleus.py` and `WarrantGraph.lean` remain byte-identical.

## Claim boundary

A positive V0 result establishes:

> In this finite declared meta-language, exact residual stagnation can certify
> current-language insufficiency and drive repeated selection, verification,
> warrant, and installation of new generator-schema instances without a
> hand-authored residual-to-repair rule.

It does **not** establish unrestricted invention of new schema constructors,
open-ended ontology creation, or globally optimal developmental planning.
