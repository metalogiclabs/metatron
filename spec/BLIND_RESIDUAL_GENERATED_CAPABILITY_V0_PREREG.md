# Blind Residual-Generated Capability V0 — Pre-Registration

**Frozen before the hidden V0 challenge is generated.**

## Objective

Test whether Metatron can synthesize a new observation capability that is not
present as a completed item in any supplied candidate list.

The public interface supplies only reusable primitive observation atoms and a
constructor grammar. Completed candidate observations must be generated by the
predictor itself.

## Public interface

The predictor receives:

1. anonymous finite state IDs;
2. the current protected-observation outcome;
3. a target behavioral class ID for each state;
4. anonymous primitive Boolean observation vectors;
5. the constructor declaration: XOR composition;
6. a SHA-256 commitment to the hidden semantics.

No composed candidate observation is supplied.

## Frozen generated language

An expression is the XOR of any nonempty subset of primitive atoms.

Expressions are canonicalized extensionally by their Boolean truth table over
the public state carrier. Constructor cost is subset_size - 1.

## Frozen search rule

1. Build the full extensional closure generated by the XOR constructor.
2. Compute the current consequential residual from the old protected quotient
   and target quotient.
3. Search generated expressions for the minimum number of invented
   observations whose joint signature refines the target quotient.
4. Among minimum-cardinality bases, minimize total constructor cost.
5. Preserve the complete equivalence class of minimum bases; choose one
   canonical basis only for serialization.
6. Separately search primitive atoms alone and report their minimum sufficient
   acquisition size.

## Hidden generator contract

The hidden world is an anonymous relabeling of four Boolean coordinates:

    (hiddenA, hiddenB, visible, noise).

The old observer sees visible.

The target quotient is equality of (visible, hiddenA, hiddenB).

Primitive atoms are an anonymous relabeling of:

- maskedA = hiddenA XOR noise;
- maskedB = hiddenB XOR noise;
- noise;
- visible.

No pair of primitive atoms is target-sufficient. Three primitive atoms are
sufficient.

The generated expressions

    maskedA XOR noise
    maskedB XOR noise

recover hiddenA and hiddenB, so two generated observations are sufficient.

## Reveal gates

G1. Hidden artifact matches the public commitment.
G2. Prediction is bound to the exact public artifact.
G3. The predictor generated the expression language from atoms/grammar only.
G4. Minimum primitive-only sufficient basis size is exactly 3.
G5. No generated singleton is target-sufficient.
G6. Minimum generated sufficient basis size is exactly 2.
G7. Minimum total constructor cost among two-expression bases is exactly 2.
G8. The hidden planted generated basis belongs to the predicted minimum family.
G9. Every predicted minimum basis is target-sufficient and irredundant.
G10. State relabeling preserves closure size, minimum generated size, minimum
     constructor cost, and minimum-basis count.

## Verdict

- BLIND_RESIDUAL_GENERATED_CAPABILITY_PASS: G1-G10 all pass.
- BLIND_RESIDUAL_GENERATED_CAPABILITY_FAIL: otherwise.

## Claim boundary

A pass establishes finite capability synthesis from a declared reusable
constructor algebra, without a supplied list of completed candidate
observations. It does not establish invention of new primitive constructors or
unbounded grammar creation.
