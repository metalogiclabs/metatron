# Residual Synergy Falsifier V0

**Status:** RED-first theorem experiment  
**Branch:** `residual-synergy-falsifier-v0`

## Question

Does the V1 additive separating-hypergraph bridge remain complete when lawful
composition can create a future observation that no generator can create alone?

The existing theorem

[
	exttt{certifiedResidualBasis_closes}
]

is retained unchanged. It is correct for its declared semantics, where basis
refinement is the intersection of singleton generator constraints.

This branch attacks the hidden separability assumption behind using that
singleton cover as a model of arbitrary compositional closure.

## Minimal causal fixture

State has three Boolean fields:

- `source`: the distinction that matters;
- `hidden`: an intermediate wire invisible to the protected observer;
- `observed`: the only protected observation.

The two initial states differ only in `source`.

Generator A copies

[
source 	o hidden
]

without changing `observed`.

Generator B copies

[
hidden 	o observed
]

without changing `source` or `hidden`.

Therefore:

- every A-only continuation leaves the two states observationally identical;
- every B-only continuation leaves them observationally identical;
- the causal path A→B separates them;
- the reversed path B→A does not.

So the new consequence is not a set-membership effect. It is generated by
composition and causal order.

## Required falsifier

Define each ordinary singleton hyperedge from the complete future closure of
that generator alone.

For the witness pair:

[
E_A=arnothing,qquad E_B=arnothing.
]

Hence even the ordinary basis ({A,B}) does not cover the consequential
residual under singleton-union semantics.

But the actual joint closure generated by ({A,B}) is sufficient for the
target future because it contains the A→B path.

The theorem

[
oxed{	exttt{ordinarySingletonCover_fails}}
]

must therefore pass together with

[
oxed{	exttt{jointBasis_sufficient}}.
]

This proves that singleton set-cover is not a complete representation of
general compositional repair.

## First replacement

The smallest generalization tested here lets one primitive repair unit itself
be a finite generator family.

Its interaction edge is

[
E_S={hoin U:operatorname{Cl}(Pcup S)	ext{ separates }ho}.
]

The fixture proves

[
E_{{A,B}}
eqarnothing
]

while both singleton edges are empty.

`pairInteraction_covers` proves that the single interaction unit ([A,B])
covers the target residual.

This is only the first replacement candidate. Because A→B succeeds while B→A
fails, a plain unordered subset still forgets scientifically relevant causal
structure. The stronger native object should therefore carry a certified causal
event structure / wiring, with ordinary singleton hypergraph cover as the
arity-one special case.

## Result interpretation

A green branch establishes:

[
oxed{
	ext{ordinary additive cover is exact only under separability;}
quad
	ext{general repair can be synergistic and order-sensitive.}
}
]

The next formal target is a causal repair object whose support projection gives
interaction coverage while preserving event order, independence, and proof
warrants.

## Claim boundary

This finite counterexample does not prove that every useful domain contains
synergy, nor that arbitrary interaction search is tractable. It proves only
that the additive singleton-union model is not complete for the already admitted
CLC-style compositional semantics.
