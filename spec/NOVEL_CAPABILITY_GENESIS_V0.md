# Novel Capability Genesis V0

**Status:** theorem + blind interface-extension experiment  
**Branch:** `novel-capability-genesis-v0`

## Objective

Formalize genuinely new observer capability as an **interface extension** that was
not already present in the observer's lawful future.

The objective dynamics remain fixed. What changes is the observer interface:
additional lawful steps and/or additional available tests may be added.

## Interface extension

`InterfaceExtension oldI newI` requires:

- every old accessible step remains accessible;
- every old available test remains available;
- test semantics on shared tests are unchanged.

Lean proves:

[
oxed{	exttt{interfaceExtension_refines}}
]

so extending the interface can only refine observer-relative future identity.

## Strict refinement

`StrictInterfaceRefinement` means:

1. every new-interface equivalence was already an old-interface equivalence;
2. at least one old-equivalent pair becomes distinguished.

Lean proves:

[
oxed{	exttt{extension_with_new_distinction_is_strict}}.
]

It also proves that a strict refinement cannot occur if the old and new
interfaces have exactly the same accessible steps and available tests:

[
oxed{	exttt{strict_extension_requires_novel_interface_witness}}.
]

This isolates the formal location of genuinely new capability.

## Concrete fixture

The objective dynamics are unchanged from Embedded Observer Ontology V0.

The coarse observer initially lacks access to the hidden test. A new interface
adds the hidden test while preserving all old capabilities.

The witness pair was previously identified but is now distinguished.

Lean proves:

- `closed_to_gained_extension`;
- `gained_hidden_separates_witness`;
- `hidden_test_acquisition_is_strict`;
- `hidden_test_is_genuinely_novel`.

## Blind minimum-acquisition test

Blind Novel Capability Genesis V0 exposes:

- anonymous states;
- old protected outcomes;
- a target quotient;
- anonymous candidate test outcome vectors.

No single novel candidate is sufficient.

The predictor must identify the minimum genuinely novel test family whose
extended observational signature is target-sufficient.

This tests interface growth rather than ordinary inference inside a fixed
interface.

## Interpretation

Accessible learning is already anticipated by the old future quotient.

Strictly new reality-refinement therefore requires a real extension of the
observer's previously lawful interface.

The developmental picture becomes:

[
	ext{old observer interface}
	o
	ext{unresolved target distinction}
	o
	ext{minimum novel interface extension}
	o
	ext{strictly refined observer-relative reality}.
]

## Claim boundary

The blind experiment searches a declared finite candidate test language. It
does not establish unrestricted invention outside that language, semantic
naming of a new capability, symbolic synthesis on infinite worlds, or a theory
of where the candidate language itself ultimately comes from. Nucleus authority
is unchanged.
